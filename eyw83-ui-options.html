EYW-83: Blog Post Listing — 3 UI Directions

Current state: dense bulleted list (<ul>) with minimal spacing. Posts are squeezed together with no visual breathing room, no excerpts, and no scannable hierarchy.

Problems with current layout

  • No visual hierarchy — every post has equal weight; nothing stands out
  • Tight vertical rhythm — list items touch each other; no whitespace between entries
  • No preview content — titles alone don't help readers decide what to read
  • Dated pattern — bulleted link lists feel like 2010-era blogs, not a modern personal brand
  • Tags unused — every post has tags in frontmatter, but none display on the index
  • No hover feedback — no interactive states to signal clickability
Option A
Card Grid (2-column)
Two-column grid of cards. Each card shows date, title, a 3-line excerpt, and tags. Hover lifts the card with a subtle shadow and accent border. The strongest visual option — conveys professionalism and content volume at a glance.
Best scanning Shows content depth Modern look Mobile-friendly
